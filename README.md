# SystemSettings

TontooOS Settings app: a 900x600 TontooUI window on the Vello renderer.
One full-bleed `Sidebar` owns the navigation column (traffic lights,
avatar pill, search field, 28 category rows) and the detail page of the
selected row. Every page is a `ScrollView` over a header row plus native
TontooUI elements (`Form`, `BasicOutlineGroup`, `Slider`, `BasicSheet`).
Follows the live system Dark/Light scheme and loads `en_us`/`de_de`
strings from `lang/`.
